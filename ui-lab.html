Accordion & FAQ

Max-height transitions with a plus icon that rotates 135Â° into a cross. Single-open and multi-open modes.

Joined

single-open
One HTML file with every component, its variants, and the CSS that drives them. No build step, no dependencies, no package to install â€” open it in a browser and copy what you need.
Yes â€” everything reads from a small set of custom properties. Change --accent and the entire library re-skins, including gradients, glows and focus rings. Seven presets ship in the top bar.
Focus-visible rings on every interactive element, real form controls under the custom skins, Escape and click-outside on overlays, and a prefers-reduced-motion block that flattens every animation.
Lift the CSS block into your global stylesheet and wrap the markup in components. Class names are flat BEM-ish, so a <Button variant="beam"> is a one-line map to .btn.btn--beam.

Separated

multi-open
Animations are transform and opacity only, so they stay on the compositor. No layout-triggering properties are animated anywhere in the file.
Modern evergreen browsers. The conic beam uses @property; where it's unsupported the border simply doesn't rotate â€” nothing breaks.
Two attributes on <html>: data-theme (light/dark) and data-accent (seven palettes). Both persist to localStorage.
